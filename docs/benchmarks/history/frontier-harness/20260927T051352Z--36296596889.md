## 5 个 error cell 的机械归因（pass@1=null 的直接原因）

| task | 阶段 | durationMs | modelOutcomes | 机械证据 |
| --- | --- | --- | --- | --- |
| datacurve/katex-multicolumn-array-spans | **infra（pre-model）** | 6404 | —（无 evidence 文件） | `docker compose ... build` 失败：`public.ecr.aws/... 429 Too Many Requests — toomanyrequests: Data limit exceeded` |
| datacurve/meriyah-explicit-resource-declarations | **infra（pre-model）** | 5498 | —（无 evidence 文件） | 同上（另一个镜像 digest） |
| datacurve/python-statemachine-state-data-scoping | **infra（pre-model）** | 6428 | —（无 evidence 文件） | 同上 |
| terminal-bench/polyglot-c-py | **provider** | 881832 | 0 | 1 条 `model-failure reason=timeout durationMs=840021`，`NonZeroAgentExitCodeError`，`pierExitCode=0` |
| terminal-bench/regex-log | **provider** | 876253 | 0 | 同上 |

- 3 个 infra error 是**模型运行之前**的环境失败：GitHub runner 从 `public.ecr.aws` 拉基础镜像时被限流（`429 Data limit exceeded`），尝试在 5.5–6.4s 内死亡，**没有任何模型调用**，也没有 evidence 文件。它们是本 run 并发 30 个 Docker 构建触发的**环境/基础设施**结果，不是任务判定。
- 2 个 provider error 的性质是**单次调用打满 CLI 自己的 per-call 上限**：每题只有 **1 条 model-request**，该请求以 `model-failure reason=timeout`、`durationMs=840021`（= `modelTimeoutMs=840000` 的边界）结束，agent 随之以 exit 1 退出（`NonZeroAgentExitCodeError`），因此该 cell 没有判定。这与前几批的 `reason=connection` 上游传输失败不同：**是 max effort 下一次调用超过了 840s**，属 provider/延迟类失败。
- `failures.json` 的机械分类：`byStage = {agent-timeout: 8, infra: 3, model: 3, provider: 2}`（共 16 个非 passed cell）；8 个 agent-timeout 的 `failedTools` 全为空（不是工具失败导致）。

## per-call 与非模型归因（spec 241 + 区间并集口径）

25 个有效 cell 的模型在飞占比为 **31%–98%**（中位区间约 88–96%）；`db-wal-recovery` 的 31% 是因为它被杀时有一次调用在飞 610s 尚未返回，并集只算到被杀时刻。单次调用中位数 4.9–25.6s，但**最大单次调用最高 953.1s**（dna-insert），另有 `scc` 683.3s、`sqlite-db-truncate` 473.1s、`httpx` 428.2s、`modernize` 423.9s、`arktype` 397.4s。非模型时间（head + 调用间隙 + tail）为 30–440s，其中 tail 通常 29–204s、调用间隙中位普遍 **0.0s**。

**新失败模式**：两条 840.0s 的单次调用（polyglot-c-py、regex-log）正好卡在 CLI 的 per-call 上限上——在 high effort 下从未出现过。也就是说 max effort 既让墙钟更长（更多预算打满），又让个别调用长到触发客户端自己的 840s 上限而直接失去判定。这与"max 会更强"的直觉相反：**在本 benchmark 的固定预算下，max 把成本花掉、却没换来判定**。
